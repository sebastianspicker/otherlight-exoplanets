# Relativity scope

Relativity-related educational calculations live under
`apps/browser/src/domain/orbits/` and `apps/browser/src/domain/simulation/`.
Their current classification is recorded in [model-registry.json](model-registry.json).

The strict V5 service does not implement relativity or time-scale conversion.
Scientific compilation rejects unsupported relativistic Browser configuration
rather than dropping it. Do not represent an Education preview as a V5
relativistic result.
