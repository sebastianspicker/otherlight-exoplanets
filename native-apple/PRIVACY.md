# Privacy policy

Otherlight for Apple platforms performs its Education calculations locally on macOS, iPhone, and iPad. It has no account system, analytics, advertising, telemetry, cloud synchronization, tracking, or runtime network client.

The app keeps current workspace context in local app preferences. Simulation values remain in memory unless you explicitly import or export a workspace, CSV, or Markdown file through the platform file picker. Bundled system data is an offline snapshot included with the app; it is not fetched from a service.

On macOS, the app uses App Sandbox with user-selected read/write file access. It does not request an outbound-network entitlement. The included privacy manifest declares no collected-data types, no accessed API categories, no tracking, and no tracking domains.

The app does not update itself. Any future iOS or iPadOS TestFlight review and any future macOS signed and notarized distribution require manual release work; there is no automated upload.

When reporting a defect, do not attach private workspace files, personal information, or credentials.
