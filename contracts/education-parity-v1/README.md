# Full Education parity contract

This contract expands the scoped `education-v4` native-alpha bridge into the
canonical scenario and output boundary used to promote individual website and
macOS capabilities. The TypeScript V4 runtime remains the fixture oracle.

The schema deliberately describes the complete V4 envelope while leaving
feature-specific photometry and dynamics objects to the exercised runtime
validators. Exact behavior is locked by parity fixtures and their declared
comparison policies rather than by schema shape alone.
